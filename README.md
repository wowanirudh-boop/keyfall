# Keyfall

Frontend prototype for an interactive falling-note piano practice player.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Prototype scope

- Searchable classical catalog with realistic sample data
- Recent-piece library and local file picker flow
- Animated 88-key falling-note player
- Working play/pause, scrubbing, speed, guide, skip, mute, and A–B controls
- Responsive desktop and tablet presentation

This version intentionally contains no backend, real audio engine, score parser,
device MIDI integration, or persistent storage.

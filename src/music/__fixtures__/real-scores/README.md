# Real-score MusicXML fixtures

These three expanded MusicXML files are promoted from the T00 Verovio spike so
the production import and waterfall colour gates cover real two-staff scores:

- `bach-bwv846.musicxml` — J. S. Bach, BWV 846
- `clara-schumann-op1-no1.musicxml` — Clara Schumann, Op. 1 No. 1
- `mozart-k545-exposition.musicxml` — W. A. Mozart, K. 545 exposition

They originate in the music21 corpus. The compositions are public domain; the
expanded files are test fixtures and are not shipped as catalog assets. Source
URLs remain documented in `spikes/musicxml/fixtures/README.md`.

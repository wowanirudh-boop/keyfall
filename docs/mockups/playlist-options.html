Set B — Working through the list

Once you are inside a piece, what does the playlist still do for you? D-032 deferred this deliberately, because “play the next one” quietly drags in the transport: what happens when a piece ends, whether an A–B loop should stop it, whether your practice speed carries over.

B1 · Nothing — tap, play, go back recommended

Player
← LIBRARY
Nocturne Op. 9 No. 2
CHOPIN · 3:22
▶1:16 / 3:22

The player is untouched. The playlist is a shortcut list you come back to.

Why this one. Zero new transport behaviour, so T12a stays small and ships. If you find yourself wanting “next” once it is in your hands, that is real evidence and it becomes its own task.

You move yourself, one tap, no surprises. The back button returns to the playlist instead of Home, and a “24 of 25” pill tells you where you are.

The cost. The player now has to know which list you came from, and the two ends need a rule (grey out, or wrap around). Modest, but it is new state.

Open questions this raises: does an A–B loop stop the advance or repeat forever? Does 0.5× practice speed carry to the next piece? What shows during the gap?

The list plays itself, with a countdown and an escape hatch at each hand-off.

The cost. Every question in the amber box is a transport decision, not a playlist one. Choosing this means T12a grows or splits again — say so and I will scope it properly rather than smuggle it in.

Set C — The works that are not in the catalog

You asked me to go and find the 39 missing works. I have started, and the honest position is in the note at the bottom of this page: the blocker is licensing, not file format, and some of these will not be sourceable at all — the 7 already-excluded rows never will be. So the playlist needs a way to show a work it cannot play, whatever the sourcing turns up. This set is about how loudly it says so.

Where the sourcing actually stands

Checked first-hand today, not from memory: piano-midi.de — the proposed second source — still cannot be read from this machine. Plain HTTP works fine generally, but that one host answers every request with an empty 418 and serves nothing over HTTPS, so its licence page is unreadable here. You can settle it in your browser in ten seconds; the steps are in my message.

The Humdrum score repositories are licence-checked: the Mozart, Scarlatti, Joplin, Haydn and Bach-chorale editions are CC BY-NC-SA 4.0 (non-commercial), and the Beethoven, Chopin, Scriabin and Vivaldi ones carry no licence at all, which means no redistribution rights. Wikimedia Commons has scans and recordings but no score data. So the obstacle is permission, not file format — converting is the easy part, and it is not what is stopping us.
